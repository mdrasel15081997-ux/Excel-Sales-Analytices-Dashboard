# 📊 Excel Sales & Business Analytics Dashboard

### 📌 Project Overview
This project focuses on end-to-end business data cleaning, date-time analysis, and operational performance tracking using Microsoft Excel. The dataset includes customer records, sales orders, and employee metrics.

### 🛠️ Tools & Formulas Used
* *Date & Time Functions:* DATEDIF, NETWORKDAYS, NETWORKDAYS.INTL, TODAY
* *Logical & Lookup Functions:* IF, IFS, AND, XLOOKUP, SUMIFS, COUNTIFS
* *Data Cleaning & Analysis:* Data Validation, Conditional Formatting, Smart Tables, and Pivot Tables

### 📈 Key Insights & Business Impact
* Calculated exact employee tenure, customer age groups, and working delivery days excluding weekends.
* Automated loyalty segmentation and discount eligibility rules to streamline sales reporting.
